## 📌 О расширении

BR-Helper (Black Russia Helper) — это расширение для браузера Chrome, предназначенное для упрощения и автоматизации работы на форуме Black Russia Online.

Расширение помогает сократить время на рутинные действия за счёт автоматических ответов по шаблонам, быстрой установки статусов и удобной кастомизации интерфейса форума. BR-Helper легко настраивается под разные роли — администраторов, лидеров и других участников, позволяя адаптировать функционал под конкретные задачи.

Основные возможности включают:
автоматические ответы на обращения пользователей;
настройку шаблонов и персональных данных (никнейм, должность);
быстрый доступ к ключевым разделам форума;
включение и отключение отдельных функций по желанию пользователя.

Это удобный инструмент для:
- Автоматического ответа на обращения пользователей
- Кастомизация форума
- Упрощения рутинных операций на форуме

## 🛠 Установка на Chrome

1. Скачайте архив с расширением из [последнего релиза](https://github.com/TheFuZeeXD/BR-Helper/releases/latest)  
    или
   ```markdown
   bash
   git clone https://github.com/TheFuZeeXD/BR-Helper
   ```

2. Распакуйте архив в удобную папку
3. В Chrome перейдите в `chrome://extensions/`
4. Включите "Режим разработчика" (правый верхний угол)
5. Нажмите "Загрузить распакованное расширение"
6. Выберите папку с распакованным расширением

## ⚙️ Установка для Android/IOS

1. Скачайте BR-Helper и Kiwi Browser в последнем релизе [Releases](https://github.com/TheFuZeeXD/BR-Helper/releases)

2. В браузере Kiwi нажмите на 3 точки и зайдите в раздел "Расширения" 

4. Включите **Developer Mode** (Режим разработчика)
5. Нажмите **+ (from .zip/.crx/.user.js)** и выберите zip-архив `BR-Helper`

если у вас IOS 

1. Скачайте BR-Helper в последнем релизе [Releases](https://github.com/TheFuZeeXD/BR-Helper/releases)  

3. Установите Браузер Orion

4. Нажмите на 3 точки и зайдите в раздел "Расширения"

5. Добавьте расширение BR-Helper


## 🎛 Функционал

### Основные возможности
✔ Автоматические ответы по шаблонам  
✔ Автоматическая установка статусов  
✔ Быстрый доступ к форуму  
✔ Кастомизация форума   
✔ Настройка под разные роли (админ, лидер и др.)  

## ⚙️ Настройка
* Введите свой **никнейм** и **должность**, чтобы они автоматически подставлялись в шаблоны ответов.
* Выберите нужную конфигурацию. Всего конфигураций: Тех. Специалист Администратор, Лидер, Старший Состав.
* Для изменения шаблонов откройте файл `content.js` и отредактируйте нужные строки.
* По желанию можно заменить задний фон форума на свое изображение.
* Перед ответом на форуме сначало заготовьте автоответ чтобы избежать ошибок.
